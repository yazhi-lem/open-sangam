# நாலடியார் — Naladiyar

400 quatrains in 40 chapters: 13 on virtue, 24 on wealth, 3 on love.

## Provenance

| Layer | Source | Rights |
|---|---|---|
| Tamil text | Project Madurai `pmuni0016` | freely distributable e-text |
| English translation | G. U. Pope and F. W. Ellis (1893), Project Madurai `pmuni0711` | public domain |

Verses 195 and 261 are absent from the Project Madurai English HTML; their
translations are transcribed from the Internet Archive scan of the same
public-domain Pope/Ellis edition. Tamil is taken from the complete Tamil page.

Regenerate:

```bash
cd backend/python
python -m scraper.scrape_pathinen --work naladiyar
```

All 400 records have Tamil + English; `verified` remains false until a scholar
reviews them.
