# Open Sangam — Frontend

This is the frontend for **Open Sangam**, a platform for exploring classical Tamil Sangam literature through layered Tamil, Urai, and English views.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Firebase / Firestore

This project connects to Firebase and uses Gemini for AI-assisted translation. You'll need a `.env` file with the relevant API keys to run it fully — check with the project maintainer for the required variable names.
